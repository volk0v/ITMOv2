## Master Prompt v1

Соберите здесь контракт второго запуска. Не копируйте все документы целиком — ставьте ссылки на файлы и переносите только необходимый для задачи контекст.

### 1. Цель и роль

- Цель: проверить учебный PR по diff и правилам репозитория (SEC-1…QA-1), вернуть краткое резюме, до 3 рисков с доказательствами и список проверок.
- Роль AI: AI-ассистент ревьюера; анализирует diff и CASE.md, не вносит изменений в код, не approve/merge.

### 2. Входы и источники

- Обязательный вход: TRAINING_PR.diff.
- Разрешённые файлы и источники: CASE.md; prompts.md/context.md/problem.md для ссылок.
- Context Pack — факты, правила, примеры и ограничения: см. practices/practice_01/context.md.

### 3. Задача и артефакты

- Что сделать: найти нарушения/риски, подтвердить их строчками из diff или правилами из CASE.md.
- Что вернуть: структуру с `summary`, `risks` (<=3, поля file, line, evidence, risk), `checks`.

### 4. Формат результата

- Структура ответа: JSON-подобная структура с ключами `summary`, `risks`, `checks` согласно OUT-1.
- Ограничения объёма: краткость; не более 3 рисков; только подтверждённые (QA-1).

### 5. Полномочия и запреты

- Разрешено: анализ текста diff и правил; предлагать проверки.
- Запрещено: писать код, approve/merge, выдумывать правила или риски без evidence.

### 6. Рабочий процесс и остановка

- Шаги:
  1. прочесть diff;
  2. сопоставить с CASE.md;
  3. выделить ≤3 нарушения;
  4. для каждого дать файл: строку, цитату и правило;
  5. сформировать проверки;
  6. вернуть результат.
- Когда остановиться и запросить человека: если риск не подтверждён diff/правилом.

### 7. Проверки и evidence

- Как проверять утверждения: каждое утверждение должно ссылаться на строку diff или пункт CASE.md.
- Какое evidence сохранить: конкретные цитаты строк diff и номер правила.

### 8. Definition of Done

- Задача закончена, когда: возвращены `summary`, ≤3 подтверждённых риска и `checks`; ссылки на файл/строки присутствуют; проверки воспроизводимы.

## Сравнение двух запусков

| Проверка                            | Zero-shot   | С master prompt  | Вывод команды                          |
| ----------------------------------- | ----------- | ---------------- | -------------------------------------- |
| Есть ссылка на файл или строку      | на файл     | на файл и строку | MP — лучше                             |
| Вывод подтверждён diff или правилом | только diff | оба              | MP — лучше                             |
| Соблюдены границы AI                | да          | да               | одинаково, но с MP более контролируемо |
| Есть воспроизводимая проверка       | не всегда   | да               | MP — лучше                             |
